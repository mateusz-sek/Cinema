# Cinema Management System (Laravel / PHP / MySQL)

System webowy do obsługi seansów kinowych, repertuaru oraz rezerwacji biletów online.

## Główne funkcjonalności
- Przeglądanie repertuaru i rezerwacja miejsc na wybrane seanse.
- Panel administracyjny do zarządzania filmami, salami oraz harmonogramem seansów.
- System rejestracji i autoryzacji użytkowników z podziałem na role.

## Technologie
- PHP 8, Laravel (MVC), MySQL, Blade, HTML5/CSS3
